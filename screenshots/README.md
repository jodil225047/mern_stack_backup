# Screenshots

The project package does not include fabricated screenshots. After starting the app with real MongoDB Atlas configuration, capture two screenshots and save them here:

1. `dashboard.png` — the populated dashboard (use your own real application records; do not seed the evaluator database automatically).
2. `applications.png` — the Applications page showing search/filter controls and your records.

On Windows, open the page in Chrome and use **Win + Shift + S**, then save the images into this directory. Add the screenshots to the README if desired.
